# 05 - 1. 깊이 우선 탐색 (Depth-First Search, DFS)
	- 정의
		- 시작 노드에서 분기를 정하여
		  최대 깊이까지 탐색하는 알고리즘
		
	- 핵심 이론
		- 1. 사용할 자료구조 초기화
			- 인접 리스트로 그래프 표현
			- 방문 배열 초기화
			- 시작 노드 스택에 삽입
		- 2. 스택에서 노드를 꺼내고, 인접 노드 삽입
		- 3. 스택에 값이 없을 때까지 반복
		
	- 특징
		- 그래프 완전 탐색
		- 시간 복잡도 O(V + E) (V는 노드 수, E는 엣지 수)
		- 재귀 함수로 구현
		- 스택 자료구조 이용
		
	- 주의 사항
		- Stack OverFlow
		- 스택에 노드를 삽입할 때 방문 배열 체크
		- 스택에 노드를 뺄 때 방문 배열 기록

# 05 - 2. 너비 우선 탐색 (Breadth-First Search, BFS)
	- 정의
		- 시작 노드를 기준으로 가까운 노드를 먼저 탐색하는 알고리즘
		
	- 핵심 이론
		- 1. 사용할 자료구조 초기화
			- 1 - 1. 인접 리스트로 그래프 표현
			- 1 - 2. 방문 배열 초기화
			- 1 - 3. 시작 노드 큐에 삽입
			
		- 2. 큐에서 노드를 꺼내고, 인접 노드 삽입
		- 3. 큐에 값이 없을 때까지 반복
		
	- 특징
		- 그래프 완전 탐색
		- 시간 복잡도 O(V + E) (V는 노드 수, E는 엣지 수)
		
	- 주의사항
		- 큐에 노드를 삽입할 때 방문 배열 체크
		- 노드를 뺄 때 방문 배열 기록

# 05 - 3. 이진 탐색 (Binary Search)  
	 - 정의
		 - 데이터가 정렬돼 있는 상태에서
		   대상값을 찾는 알고리즘
		 
	- 핵심 이론
		- 1. 현재 배열의 중앙값 선택
		- 2. (중앙값 > 대상값), 왼쪽 배열 선택
		- 3. (중앙값 < 대상값), 오른쪽 배열 선택
		- 4. (중앙값 == 대상값), 종료

	- 특징
		- 구현 및 원리가 비교적 간단
		- 시간 복잡도 O(log n)
		- 중앙값 비교를 통한 대상 축소 방식
